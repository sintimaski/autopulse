# Plans (disposable)

Use this folder for **time-boxed or initiative-specific** notes: spikes, LLM task breakdowns, rollout sketches, and other working documentation that should not live beside governed specs.

- Governance: `docs/DOCUMENTATION_GOVERNANCE.md` and **Non-permanent and working documentation** in `.cursor/rules/documentation-and-context.mdc`.
- Promote durable outcomes through the normal doc path (for example `DEVELOPMENT.md`, `docs/ops/`, or `docs/contracts/`) instead of keeping stale plans here after merge.
